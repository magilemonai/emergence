# engine/CONTRACT.md — the sim API (FROZEN)

Implementers: match these signatures exactly; consumers: rely on nothing else. Propose changes in your work-order
report under "contract proposals"; do not edit this file or `types.js`.

```js
import { createSim } from './sim.js';
const sim = createSim({ cfg, eras: [origins, symbolic, ...], seed: 12345, legacy: null });
```

## sim
| member | signature | contract |
|---|---|---|
| `sim.state` | `State` | the single state object; read freely, mutate ONLY through actions/tick |
| `sim.tick(dt)` | `(dt:number) => {flows:number}` | advances `state.t`; dt clamped to `[0, 0.5]`; runs the graph pass then each installed era's `tick`; deterministic |
| `sim.apply(action)` | `(a:Action) => {ok:boolean, reason?:string}` | validates with the era's `actions[a.type].can(sim,a)`; on ok runs `.apply(sim,a)` and appends `{...a, t}` to `state.log` |
| `sim.can(action)` | `(a:Action) => boolean` | pure; no mutation |
| `sim.available(era?)` | `(era?:number) => Action[]` | every action currently `can` for the era (default active) — the bot's menu |
| `sim.rng()` | `() => number` | mulberry32 on `state.rng.s`; the ONLY randomness in the engine |
| `sim.snapshot()` / `sim.restore(s)` | deep copy in/out | structuredClone-equivalent (JSON safe: no functions in State) |
| `sim.replay(seed, log, until?)` | `(seed:number, log:Action[], until?:number) => State` | rebuilds from a fresh sim by ticking 0.1s steps and applying logged actions at their `t`; result must equal the live state (test-enforced) |
| `sim.addNode(def)` / `sim.removeNode(id)` | `NodeDef` | eras build the graph; adding rebuilds edges |
| `sim.node(id)` / `sim.stock(res)` / `sim.rate(res)` | accessors | `rate` = net per second over the last tick |
| `sim.setMult(nodeId, key, value)` | multiplier registry | effective rate = base × Π `node.mult[*]` |
| `sim.openEra(n)` | installs era n if not installed; sets `era`/`maxEra`; calls `eras[n].open(sim)` | the handoff seam |
| `sim.goal(era?)` | `=> {progress:0..1, ready:boolean, label:string}` | from the era's `goal(sim)` |
| `sim.voice(era?)` | `=> string|null` | the machine's current line for that stratum |
| `sim.muted()` / `sim.setMuted(b)` | offline catch-up flag | live-only systems skip while muted |
| `sim.eras` | `{[n]: EraModule}` | installed modules |
| `sim.cfg` | the cfg object | read-only by convention |

## EraModule (each `engine/eras/*.js` default export)
```js
export default {
  id: 1, name: 'Origins', height: 700,
  install(sim) {},            // add stores/nodes/cfg block; called once when the era opens (Origins at createSim)
  open(sim) {},               // handoff seam (seed carried resources); may be a no-op
  tick(sim, dt) {},           // era rules after the graph pass; must check sim.muted() for live-only systems
  actions: { inscribe: { can(sim, a) {}, apply(sim, a) {} }, buy: {...}, ... },
  goal(sim) { return { progress, ready, label }; },
  voice(sim) { return null; },
  layout: { anchors: { nodeId: { x, y } }, verbs: ['inscribe','quarry'], goal: 'logicMachine' },
  done(sim) { return false; }
};
```
Actions are named per era; the shared ones every era exposes: `buy {node, n}`, `pause {node, on}`.
Cross-era actions (reach-back) are actions on the TARGET era: `sim.apply({type:'buy', era:1, node:'foundry', n:1})`.

## Determinism rules (tested)
- No `Date`, `Math.random`, `performance`, timers, or DOM in `engine/`.
- Iteration order is insertion order (never `for…in` over objects whose insertion order isn't controlled).
- `sim.replay` of `state.log` must reproduce `state` exactly (deep-equal after stripping `log`).
